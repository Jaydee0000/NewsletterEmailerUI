# CCJ Newsletter Distributor w/ UI

A JavaFX newsletter distribution application for loading subscriber lists, importing HTML email templates, generating previews, and sending newsletters to validated recipients.

Designed for Collin County Journal newsletter operations.

## Features
Graphical user interface (JavaFX)

Import HTML newsletter templates

Import Excel subscriber lists

Preview newsletters before distribution

Validate recipient lists

Subject line customization

Bulk email distribution

Built-in safety confirmation before sending


## How To Use
### Step 1: Launch Application

Run the application and wait for the Newsletter Distributor window to appear.

### Step 2: Enter Sender Credentials

Fill out:

Sender Email
Sender Password (Gmail App Password)

### Step 3: Import Newsletter HTML

Click:

Import HTML

Select your newsletter HTML file.

The application will display the loaded file name once imported successfully.

### Step 4: Import Email Spreadsheet

Click:

Import Excel

Select the Excel file containing recipient emails.

### Step 5: Scan Email List

Click:

Scan Emails

The application will:

Read email addresses from the spreadsheet
Count total recipients
Display the number of loaded emails

### Step 6: Verify Recipients

Click:

Verify Emails

Review the generated list before sending.

### Step 7: Configure Subject Line

Enter the desired email subject.

### Step 8: Send Preview

Enter a preview email address.

Click:

Send Preview

Review the newsletter in your inbox before continuing.

### Step 9: Send Newsletter

Type:

SEND

into the confirmation field.

Click:

Send

The application will begin distributing the newsletter to all validated recipients.

#### Safety Features

The application requires:

Valid sender credentials
Loaded HTML template
Loaded recipient list
Email verification
Preview email generation
Manual SEND confirmation

before allowing mass distribution.
